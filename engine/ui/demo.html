2-44. STARTER SYSTEM — DESCRIPTION

The starter motor is energized through the start relay when the master switch is ON and the transmission is in N (neutral). The starter draws high current; verify the batteries are fully charged and the NATO slave receptacle connections are clean before condemning the starter. If the engine does not crank, perform the no-crank checks in sequence (battery → master switch → start relay → starter) before removal.
